# Asset botanici della versione 0.1.3

Generati con il **tool integrato image_gen**, modalità generate, usando le tre
immagini dell'utente come riferimenti di stile. Nessun servizio a pagamento o
connessione esterna è richiesto per mostrarli nell'app.

## File inclusi nel progetto

- `public/art/garden-welcome-v013.png`: panorama per la schermata iniziale.
- `public/art/botanical-corner-v013.png`: ornamento botanico con trasparenza reale.
- `assets/app-icon-v013.svg`: icona vettoriale disegnata nel progetto, non generata
  con image_gen. La versione attiva è copiata anche in `assets/app-icon.svg` e
  convertita nei formati desktop dal generatore di icone Tauri.

Le immagini sorgenti generate rimangono nella cartella generated_images di Codex;
l'app usa esclusivamente le copie incluse in public/art. Non distribuiamo gli
screenshot di riferimento dell'utente come sfondi o come interfaccia.
